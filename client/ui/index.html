          使用说明

          • 首次使用先填写服务器地址；之后可在这里添加、切换多台服务器。每台服务器的账号和联系人分别显示。
          • 在所选服务器上注册账号并设置密码，以后用该账号和密码登录。请妥善保管密码。
          • 私钥和解密后的聊天记录保存在当前 Windows 用户的应用数据中（默认位于 %APPDATA%\Chat\default），由 Windows 安全存储加密保护。账号的加密聊天身份与这份本机私钥绑定，请在原 Windows 用户下使用。
          • 只删除 Chat.exe 或下载的 ZIP 文件，不一定会删除上述本机数据；删除本机用户资料或应用数据、重装系统，或改用另一 Windows 用户后，若原私钥已丢失或无法读取，可以凭用户名和密码重新登录并重建设备身份，但旧私钥和聊天记录无法恢复。旧设备退出登录，联系人需重新核对安全码。
          • 首次向某人发起聊天时，只能先发一条消息；等对方接受后，才能继续发送。
          • 删除联系人会撤销对方继续向你发消息的权限，已有聊天记录仍保留；“清除会话”只把它从会话列表隐藏。
          • “在线”表示你已成功连上服务器。对方不在线时，服务器暂存加密消息，等对方连接后再送达。“服务器已保存密文”不代表对方收到；“对方客户端已接收”也不代表已读。
          • 聊天右上角“···”可发送位置或查找本机聊天记录；实时位置最多共享一小时，应用离开前台、断线或退出时停止。定位失败可手动发送固定坐标。
          • 聊天前可通过见面或可信通话，和对方比较完整的安全码；一致后点击“已通过可信渠道核对一致”。
          • 账号连续 7 天未成功连接服务器，服务器会删除该账号及服务器上的密钥、加密消息，无法从服务器恢复。打开应用或输入密码但连接失败不算成功；请至少每周登录，并确认客户端显示“在线”。本机历史记录可能仍在。
