# Android 验证范围

当前源码为 Android 0.5.8（versionCode 24）。本轮 75 项 JVM 测试通过，1 项可选基准跳过；lintDebug 为 0 个错误、21 个警告；debug、release 和设备测试 APK 已构建。新增会话索引失效键与历史查询回归，位置消息可保存地址。普通 AlertDialog 共用动画和圆角按钮，设备主题检查已编译，尚未运行。系统地址服务返回、实际动画、触摸、熄屏、后台下载和覆盖安装等交互仍需真机验收。

更新下载使用独立 `dataSync` 前台服务，三十分钟总期限覆盖网络与本地校验；下载期间申请最多三十五分钟的 CPU 唤醒锁，并在任务结束时立即释放。熄屏、普通后台或 Activity 销毁不会主动取消，但进程被系统强行停止、设备重启或后台网络被禁止时不能保证继续。校验完成后仍须用户手动点击安装。

正式版包名为 `com.example.chatandroid`，使用独立发布签名；旧调试版为 `com.example.chatandroid.debug`，沿用旧证书。两条安装渠道数据独立；APK 校验不等于已在手机安装或验证覆盖更新。

本版尚未完成真实设备切网、长列表帧率、键盘、快速会话切换和通话小窗专项复测。应用被系统停止后不保证消息、来电或期限提醒。JVM 测试及预览不能证明远端音视频可用。

详见 [项目验证范围](../VALIDATION.md)及 [签名与渠道说明](RELEASE.md)。

文件格式通过 Java/Node 共享 AES-GCM 向量及认证标签篡改测试。文件选择与另存、缓存、取消任务和卡片已编译；系统选择器及实际手机文件收发仍待真机验收。

媒体测试覆盖文件头、无扩展名提供者和图片采样限制。图片预览、VideoView 播放及关闭清理已编译，尚未进行真实手机图片、视频播放及关闭期间账号切换验收。

本版还修改续认证后的账号期限刷新。服务端对应逻辑已通过自动测试；Android 端的期限显示及连续在线行为尚需设备和部署环境检查。
