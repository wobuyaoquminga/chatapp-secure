# 升级到支持重新登录的服务器

本次需要更新服务器与两端客户端。服务器旧数据库无需清空，启动时自动升级到 V7；保留 `/var/lib/chat/data` 与 `/etc/chat/chat.env`。

将新的 `Chat-Ubuntu-Deploy.tar.gz` 上传到服务器的用户目录，执行：

```bash
tar -xzf Chat-Ubuntu-Deploy.tar.gz
sudo bash ubuntu-deploy/install.sh
sudo systemctl status chat --no-pager
sudo journalctl -u chat -n 50 --no-pager
```

安装脚本保留已有数据库、JWT 和数据库密码。已有 Nginx HTTPS 配置无需重建，客户端继续使用管理员配置的 HTTPS 服务器地址，例如 `https://chat.example.com`。不要删除 `/var/lib/chat/data`。

升级后再安装新客户端。重新安装或清除本地数据后，原账号仍可用密码登录，但旧聊天记录无法恢复；更换身份会使旧设备退出，已有联系人需要重新核对安全码。
